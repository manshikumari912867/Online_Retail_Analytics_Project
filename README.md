# 📊 Online Retail Executive Data Analytics Web App

An end-to-end Data Analytics platform and Flask web application built to process, clean, and visualize 500,000+ retail transactional records for executive business decision-making.

---

## 💡 Key Features & Business Insights
- **500k+ Transaction Cleaning:** Automated ETL pipeline using Python Pandas, filtering invalid records and zero-unit prices.
- **Monthly Revenue Trend:** Interactive visualization of 2011 seasonal sales growth and Q4 revenue spikes.
- **Top 10 Global Markets:** Identified top-performing international markets (excluding UK).
- **High-Value Customer Segmentation:** Grouped customer data to identify core revenue drivers.
- **Automated Multi-Tab Excel Export:** Integrated automated `.xlsx` report download using OpenPyXL.

---

## 🛠️ Tech Stack
- **Data Engineering:** Python, Pandas, NumPy
- **Backend:** Flask REST API
- **Frontend & Visuals:** HTML5, CSS3, Matplotlib, Chart.js
- **Reporting:** OpenPyXL
- **Version Control:** Git & GitHub
